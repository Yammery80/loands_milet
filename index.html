Configura Firebase — solo una vez
Paso 1
Crea el proyecto Firebase
Ve a console.firebase.google.com → Agregar proyecto → nombre → sin Analytics → Crear.

Authentication → Comenzar → Google → Habilitar → Guardar

Firestore → Crear base → Modo producción → Región nam5

Reglas Firestore → pega esto y publica: 
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /users/{userId}/{document=**} {
      allow read, write: if request.auth != null
        && request.auth.uid == userId;
    }
  }
}
Paso 2
Copia tu configuración
Configuración ⚙️ → Tus apps → </> Web → Registrar → copia los datos.
