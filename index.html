Configura Firebase una sola vez
Paso 1
Crea tu proyecto Firebase
Ve a console.firebase.google.com → "Agregar proyecto" → ponle un nombre → desactiva Analytics → Crear.

Luego: Authentication → Comenzar → Google → Habilitar → Guardar

Luego: Firestore → Crear base de datos → Modo producción → Región: nam5 → Listo

Luego ve a Reglas de Firestore y pega esto: 
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /users/{userId}/{document=**} {
      allow read, write: if request.auth != null && request.auth.uid == userId;
    }
  }
}
Paso 2
Copia tu configuración
En Firebase: Configuración del proyecto ⚙️ → Tus apps → </> Web → Registrar app → copia los datos que aparecen.
API Key
